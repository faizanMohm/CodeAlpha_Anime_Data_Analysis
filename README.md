# 🚀 CodeAlpha Data Analytics Internship: Anime Data Analysis 📊

👋 **Welcome to my project repository!**  
This space showcases my work for the **CodeAlpha Data Analytics Internship**. To demonstrate a complete, real-world data pipeline, I focused on a single theme—**Anime Statistics** 🎌—and took the data from extraction all the way to a professional visualization.

---

### 🏆 Tasks Completed

**🌐 Task 1: Web Scraping**
- 📥 **Extracted:** Scraped data for the Top 1000 Anime directly from MyAnimeList.
- 🧹 **Processed:** Handled raw HTML structures, cleaned the extraction, and exported it securely to a CSV file.

**📈 Task 2: Exploratory Data Analysis (EDA)**
- 🛠️ **Data Cleaning:** Used Python to handle missing values and format data types for accurate mathematical operations.
- 🔍 **Trend Discovery:** Generated insightful visualizations to uncover patterns in Anime formats and rating distributions.

**🎨 Task 3: Data Visualization**
- 🖥️ **Dashboarding:** Designed a highly interactive and professional dashboard using **Power BI**.
- 💡 **Key Insights:** Highlighted core metrics such as Total Anime Count, Format Trends, and the Top 10 Highest-Rated Anime worldwide.

---

### 🛠️ Tools & Technologies Stack
- 🐍 **Python:** `BeautifulSoup`, `Requests`, `Pandas`, `Matplotlib`, `Seaborn`
- 🟨 **Microsoft Power BI:** Data Transformation, Modeling, and Dashboard Creation
